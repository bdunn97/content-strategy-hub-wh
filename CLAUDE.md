# CLAUDE.md: Wilder Home Creator Content Strategy

## What this is
A single-page internal site ("Wilder Home Creator Content Strategy") for Wilder Home's creator and
UGC content work.
Hosted on Netlify and deployed from the GitHub repo `bdunn97/content-strategy-hub-wh`: every push
to `main` redeploys the live site.

- Live site: https://content-strategy-hub-wh.netlify.app/ (Netlify; paused while out of credits)
- Also live on GitHub Pages: https://bdunn97.github.io/content-strategy-hub-wh/ (free; updates on
  every push to `main`, root folder). Use this one to check a publish while Netlify is paused.
- Local preview: http://localhost:4324 (`.claude/launch.json` "hub-preview", or `Start Hub.bat`) Layout and styling mirror the Content Marketing Hub
(sticky tab bar, uppercase headings, red accent, 9:16 video carousels with a pop-up player).

Tabs (in nav order; page ids in brackets):
- Competitor Analysis ▾: Ad Library [`ad-library`], Organic Content [`organic-content`]
- Creative ▾: Creative Brief [`creative-brief`], Scripts [`scripts`]
- Creators ▾: Potential [`potential-creators`], Signed [`signed-creators`]
- Content Calendar [`content-calendar`]
- Strategy [`strategy`]

Ad Library holds the competitor video carousels and is the landing page (first `<main>` in the
file). Old links `#competitor-ads` and `#strategy-proposal` redirect to `#ad-library` and `#strategy`. Pages without content
yet show a "No content yet" placeholder.

## Structure
```
index.html            The whole site: CSS, HTML and script. Tabs are <main class="page" id="...">
                      blocks plus a matching <a class="tab" data-tab="..."> link in the nav.
videos.js             List of competitor videos, grouped by brand. Generated; don't hand-edit.
update-videos.ps1     Rebuilds videos.js from the "Competitor Ads" folder.
Competitor Ads/
  <Brand>/            One folder per competitor brand = one carousel row on the Ad Library page.
    <Brand> NN.mp4    "Music Only" in the filename shows a "Music only" badge on the card.
site-data/
  ad-shot-lists.json  Shot list per competitor video: structure, takeaway and shots
                      (n, time, shot, action, text). Each "id" is the video title slugged
                      ("Cozey 01" -> cozey-01, "Music Only" dropped). Shown as a collapsible
                      "Shot list" under each Ad Library card; videos without an entry get none.
                      Loaded with fetch, so it only shows over http (Netlify or localhost:4324).
  potential-creators.json
                      Generated by sync-sheets.ps1 from the user's local spreadsheet. Don't hand-edit.
strategy-content.md   The Strategy tab's content. The page fetches and renders this Markdown file
                      (headings, lists, tables, bold/italic). The "# Title" line becomes the page
                      heading (text before ": " is the eyebrow); a first all-italic line becomes the
                      subtitle; each "## Section" gets a sidebar link. Edit the file and refresh.
Wilder Home Ad Concepts.docx
                      Source for Creative > Scripts. The user edits it in Word.
sync-docs.ps1         Reads the .docx (temp copy) and writes site-data/ad-concepts.json
                      ("Concept N. Title", a "Vibe: / Good for: / Length:" line, then labeled
                      sections with bullet items). The page normalizes labels so every concept
                      looks the same: Visual moments, Script, On-screen text, Content examples.
                      Concepts sort by number; "X"/blank shows as TBD with an "In progress" badge.
                      Content examples matching a competitor video title (e.g. "Cozey 06") show
                      as playable thumbnails.
sync-sheets.ps1       Reads local Excel files (list in $Sources at the top) and writes site-data/*.json.
                      Reads a temp copy, so the workbook can be open in Excel.
serve.ps1             Local server for http://localhost:4324 (also used by .claude/launch.json
                      "hub-preview"). Start Hub.bat starts it with a double-click.
```

- No build step and nothing to install. Netlify serves the repo as is (publish directory `/`).
- Video thumbnails are frames from the videos themselves (no separate image files).

## Common tasks
**Update the site from the spreadsheet** (the user edits it locally, then asks e.g. "update the site
from my spreadsheet" / "sync my creators")
1. Run `powershell -ExecutionPolicy Bypass -File .\sync-sheets.ps1`.
   Source: `C:\Users\bdunn.NEWAGE\OneDrive - NewAge Products\Desktop\Wilder Home\Influencer\Wilder Home Potential Influencers.xlsx`
   → `site-data/potential-creators.json` → Creators ▾ Potential page.
2. Summarize what changed (`git diff --stat site-data/` plus added/removed creator names).
3. Show the preview (localhost:4324, `#potential-creators`), then commit and push when the user says to publish.
- The page finds columns by header text (Name, URL - IG, URL - TT, Followers - IG/TT, Niche, Notes),
  so column order can change. A brand-new column shows up as an extra table column automatically.
  If a header is renamed so it no longer matches, update `COLS` in index.html.
- The live site and GitHub repo are viewable by others: everything in a synced column is published.
  The spreadsheet's Email column is left out via `Exclude` in `$Sources` (sync-sheets.ps1); add
  any other private column there. Only remove Email from `Exclude` if the user asks.

**Update Scripts from the ad concepts doc** ("update the scripts" / "sync my ad concepts")
1. Run `powershell -ExecutionPolicy Bypass -File .\sync-docs.ps1`.
2. Summarize what changed, then show the preview at localhost:4324 `#scripts`.

**Add or remove competitor videos**
1. Put the files in `Competitor Ads/<Brand>/` (new brand = new folder).
2. Run `powershell -ExecutionPolicy Bypass -File .\update-videos.ps1` to rebuild `videos.js`.
3. Preview with the "hub-preview" launch config, then commit and push.

**Add a new tab**: add a `<main class="page" id="new-id" hidden>` section and a nav link with
`class="tab"`, `href="#new-id"` and `data-tab="new-id"`. For a dropdown item, add the link inside
that `.menu` (no `tab` class) and add the id to the dropdown button's `data-pages`. Routing picks
it up automatically; the first `<main>` in the file is the default page.

## Rules
- Keep every video file under 100 MB (GitHub's per-file limit). Compress anything larger first.
- Commit and push only when the user asks; pushing to `main` publishes the live site.
- Keep the existing look (Content Marketing Hub style) unless asked to change the design.
